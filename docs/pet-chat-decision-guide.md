## 一、核心理解（读 1 分钟）

### 问题
你现在有"**成稿台**"（段落级编辑面板）+ "**热点库**"（选题），但两者：
- 对话能力被锁在成稿台里（不能全局用）
- 没有"创意伙伴"体验（快速灵感→初稿→精编）
- Skill（写作风格）无法复用、学习、分享

### 解决方案：三件事

```
1️⃣  Skill 系统中台
   让用户能创建、维护、分享、导入预设
   → 写作风格可积累、可复用
   
2️⃣  AI 宠物对话窗
   从成稿台独立出来，悬浮全局可用
   → 热点/链接/描述 → 自动推荐 Skill → 生成初稿 → 投喂成稿台
   
3️⃣  快捷工具集
   段落选中 → 一键"去AI味"/"润色"/"改写"/"生成SVG卡"
   → 加速编辑迭代
```

### 结果
用户完整创作流：
```
灵感来了 
  ↓ [宠物对话] 蒸馏资料、选Skill、生成初稿
获取初稿
  ↓ [投喂成稿台] 一键填入
精编细化
  ↓ [快捷工具] 去AI味、润色、插卡
完稿发布
```

## 三、实施建议（读 1 分钟）

### ✅ 推荐启动理由

1. **现有基础完整**
   - `studio_pipeline.py` 改稿能力已有（快捷工具复用）
   - `ai_article.py` 生成能力已有（对话引擎复用）
   - PostgreSQL 表结构可扩展（Skill 表新增）

2. **收益明确**
   - 创作效率 ↑ 40%（一键生成初稿）
   - Skill 复用率 ↑（团队能沉淀风格）
   - 对话历史可追溯（改稿链路清晰）

3. **技术风险低**
   - 不改现有路由、表结构（新增而已）
   - 前端独立组件（不耦合成稿台）
   - 意图识别可从规则开始（后续升级 LLM）

### ⚠️ 需要重点关注

1. **LLM 调用频繁 → 成本 & 延迟**
   - 缓解：本地规则优先（去 AI 味）；缓存热用例；用户可选"完整/快速"模式

2. **Skill 质量不稳定**
   - 缓解：用户反馈改进；提供多版本选择；官方预设库持续维护

3. **对话历史泄露风险**
   - 缓解：严格权限检查；对话加密存储；定期删除策略

## 七、常见问题

### Q: 为什么不直接改成稿台的对话面板？
**A**: 成稿台的对话是**局部的**（改稿建议），宠物是**全局的**（创意伙伴）。两个用途不同：
- 成稿台对话：用于改稿反馈，聚焦当前稿件
- 宠物对话：用于创意启发，可发起任何创作

分离后，成稿台保持专注，宠物可复用于热点库、灵感面板等其他页面。

---

### Q: Skill 蒸馏（从链接提取风格档）那么复杂，要放到 Phase 1 吗？
**A**: 不要。放到 Phase 5。理由：
- Phase 1-3 用户可以手工编写 Skill 或复制预设
- Phase 5 再加"自动蒸馏"优化体验
- 分阶段交付，减少初期风险

---

### Q: 对话引擎的 NLU（意图识别）用 LLM 还是规则？
**A**: 两步走：
- **Phase 2**：用规则（快速、成本低）+ 关键词匹配
- **Phase 6+**：升级到 LLM 意图识别（更准确，成本↑）

用户不会感受到差异，只会觉得"越来越聪明"。

---

### Q: 宠物会不会抢成稿台的饭碗？
**A**: 不会。位置不同：
- **成稿台**（`/paper`）：**编辑车间**，细节到段落级
- **宠物**（浮窗）：**创意助手**，快速启动到初稿

用户流向是：宠物（生成初稿）→ 成稿台（精编）。两者互补。
