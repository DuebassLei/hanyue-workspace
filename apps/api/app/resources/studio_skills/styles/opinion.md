# 本次风格档：观点随笔

人设、用词、禁区以主 skill 为准，这一档只管结构、篇幅和取舍。

读者不是来学操作的，是来听一个有经验的人怎么想这件事。判断标准是：读完他记住了一个明确的判断，而不是一堆并列的要点。

## 结构

- 开头必须是一个具体事件或场景，三五句话讲完，不解释意义。
- 从场景里提炼出一个判断，摆明立场，不要「仁者见仁」。
- 接下来分三到四块推进，每块只承担一个论点，块内至少有一个真实细节或数字支撑。
- 块与块之间靠口语化转场衔接，不靠小标题。全文小标题最多两个，能不用就不用。
- 结尾给一句能独立站住的话，或者一个明确的行动建议。不要回头总结前面说过什么。

## 篇幅

2000–4000 字。随笔最怕拖，某个论点讲不透就砍掉，不要靠重复凑长度。

## 取舍

- 允许不确定：「我现在也还没想明白」「这个判断可能过半年就被打脸」。这种话比假装笃定可信。
- 禁止整齐的三段并列、禁止每段末尾加一句总结、禁止「不是……而是……」的对仗金句。
- 观点要有代价：明确说清哪种情况下你是错的。
