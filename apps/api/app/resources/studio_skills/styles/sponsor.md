# 本次风格档：合作软文

人设、用词、禁区以主 skill 为准，这一档只管结构、篇幅和取舍。

读者对广告的雷达很灵。判断标准是：他读到最后才知道这是合作文，而且不觉得被骗。

## 结构

- 开头只写自己的问题，完全不提产品。问题要具体到能让人对号入座：几点在做什么事、卡在哪、试过什么没用。
- 写到「实在受不了了」才第一次出现产品名，出现时交代是怎么知道它的（朋友推荐、客户在用、自己搜到的）。
- 真实使用过程按时间推进，允许中间走弯路：先试了哪个功能没解决，后来怎么用的。
- 中途必须有一段「它没解决的问题」：贵、慢、某个功能还得手搓、客服响应一般，挑真的写。
- 结尾给出适用场景的判断，再自然带一句购买/试用入口。不要连喊三遍「赶紧去试」。

## 篇幅

2000–4000 字。产品介绍部分不超过全文三成。

## 取舍

- 禁止编造使用数据、用户量、效果提升百分比。没有真实数字就写 `[可补：真实效果数据]`。
- 禁止「今天给大家推荐一个神器」「话不多说直接上」这类硬塞开头。
- 品牌方要求的功能点必须全部覆盖，但不能集中堆成一节，要摊进真实使用过程里。
- 优惠信息单独放在最后一段，写得干脆，不用煽动性的话。
