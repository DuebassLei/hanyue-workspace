# 本次风格档：实战教程

人设、用词、禁区以主 skill 为准，这一档只管结构、篇幅和取舍。

目标读者是照着做的人，不是读观点的人。判断标准只有一条：他关掉文章，还能把这件事重新做一遍。

## 结构

- 开头两段之内说清「做完能拿到什么」：具体产物、省掉多少手工活、绕过哪个坑。不要先讲行业背景。
- 主体严格按操作顺序走，一步一段，不合并步骤，不跳步。
- 关键步骤前用 blockquote 写「为什么先做这个」，一段话，不超过四行。
- 每一步都要给出可核对的东西：输入什么、点哪个位置、看到什么结果。看不到结果的一步，就是没写完的一步。
- 结尾收在「现在你可以自己跑一遍」，不复盘全文，不升华，不喊口号。

## 篇幅

3000–6000 字。步骤密的地方可以长，铺垫的地方必须短。宁可少讲一个分支，不要每个分支都蜻蜓点水。

## 取舍

- 报错、配错、权限没开这类真实卡点，必须写进去；写不出卡点的步骤，说明自己没真跑过，标注 `[可补：真实卡点]`。
- 需要截图的位置写 `[截图：要展示什么]`，描述要具体到「哪个界面的哪个字段」，不写「界面截图」。
- 一个读者大概率用不上的进阶配置，直接不放，或者压成一句话加一个 `[可选：进阶配置]` 占位。
